# 個人網站設計與內容指引

更新：2026-09-12。這是可調整的起點，不是固定設計規格。

## 目標與自由度

讓讀者快速理解 Chi-An Chen 的研究方向、工程能力，以及值得深入了解的作品。
先以研究／工程合作對象及潛在雇主為主要讀者，不必把網站做成完整履歷。
Chi-An Chen 作為暫定顯示名稱；論文作者名稱依來源保留 Chi-An Chen。

目前沒有指定必須照做的網站、配色、字體、版型、章節數或動畫數量。
可以採明亮、深色或中性色系；選擇應服務內容與閱讀體驗。
「Apple-inspired」只代表對細節與層級的重視，不要求仿製 Apple。

## 可直接使用的設計要點

- 首屏先回答「你關注什麼、做過什麼、下一步看哪裡」。短介紹配一個主要作品入口即可，聯絡連結可作次要入口。
- 讓作品內容決定排版。可以用開放式列表、圖文敘事或必要的卡片，不預設整頁卡片牆。
- 先挑約 2–3 個有內容與證據的案例；數量可減少，不為湊版面加入空泛專案。
- 每個案例優先展示問題、本人貢獻、方法、成果及來源連結。技術名稱應協助理解貢獻，不變成徽章清單。
- 用一致的字級層級、對齊與間距建立品質。正文保持舒適行長；手機不為維持標題行數而縮小到難讀。
- 字體以可讀性、可用授權和中英文涵蓋為準。系統字體可用，不必購買或假設高價字體存在。
- 配色可先採中性底色與少量強調色，再依設計探索調整；深色模式與主題切換不是必要功能。
- 沒有合適圖片時，文字主導的版面成立。需要解釋方法時，可使用依真實資訊製作並標為示意的流程圖。
- 生成圖片可以探索構圖，不能冒充研究結果、產品截圖、合作證明或本人照片；不要使用隨機圖庫影像假裝作品素材。
- 動態效果用於回饋或引導閱讀。靜態頁面也可以有完成度；不要求視差、固定捲動、GSAP 或連續動畫。
- 手機閱讀、鍵盤操作、可見焦點、對比及減少動態效果設定優先。必要內容在無動畫、無 JavaScript 時仍可讀取。

## 內容取捨

PDF 只供製作時參考，不是網站需求清單。可忽略 GPA、證照、舊獎項、
較不相關經歷、聯絡細節或缺乏足夠說明的案例，不必要求先更新全部 PDF。

網站可從短介紹、精選作品、精選研究、簡短背景和聯絡入口開始；
區塊可合併或省略，不必建立空的文章頁、完整年表或下載履歷按鈕。

實際使用的資訊必須忠於來源。published、accepted、under review 與 ongoing
不可混用；不確定是否仍然有效的「目前」狀態可省略或留在本機待確認，
不要憑舊履歷推斷最新狀態。成果數字必須保留適用條件，無法支持就不用。
取捨可以自主進行；只有必須公開使用而無法安全省略的關鍵事實才需要詢問。

## 檔案與階段邊界

- reference_data/ 與 PDF 留在本機，不上傳 Git，也不成為網站建置依賴。
- 正式網站只使用經篩選的文字與預定公開的網站資產。
- 專案規則、這份指引與網站原始碼可納入版本管理。
- 本機草稿及生成的探索稿放在 work/ 或 docs/design-exploration/，預設忽略。
- 先整理內容並解釋設計方向，再依當次任務製作適量視覺稿或小型原型。
  不強制三案或逐區塊生圖；只有當使用者要求比較方案時才擴大探索數量。
- 不因缺少非必要履歷內容或指定參考網站而停止進展。
